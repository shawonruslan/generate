# v27.12 - Desktop UI/UX pass: video card, theme presets, realistic phone scenes

Bundle: **tamplate-vpn** (desktop profile: `template`). Desktop app version **27.12.0+7**, Android app **2.3.1 (versionCode 4)**.
Nothing was removed - every v27.11 feature (missed-slot recovery, mix gap fill, alerts, installer...) is untouched.

## 1. Upload Queue -> "Video Content (Live Wallpaper / Charging Animation)" card (desktop)
File: `desktop/lib/ui/screens/upload_queue_screen.dart` (`_VideoUploadCard`).

* **Step flow** in the card header: `1 Type -> 2 Video -> 3 Cover -> Queue` chips light up as you go.
* **Video type** is now two big option cards (Live Wallpaper / Charging Animation) with icon, description and spec chips
  (`1080x1920+`, `<= 30 s`, `MP4 / MOV`). Click = select; the active one glows in the theme colour.
* **Video file**: one full-width drop zone. After a file is picked it turns into a file tile: cover preview, LIVE/CHARGE badge,
  extension badge, size vs the 50 MB limit (green check / red warning), **Replace video** and **Remove**.
* **Cover thumbnail** filmstrip: 5 dashed 9:16 placeholders (numbered) while empty, shimmer while frames are captured, then
  the 5 real frames with hover zoom, "Use as cover" / "COVER" ribbon and a check badge on the chosen one.
* **Footer**: a status pill (info / spinner / success / error colour + icon) and the "Queue Live Wallpaper" button.
  The button is disabled with a tooltip until a video and a cover are chosen.
* Fully responsive: side-by-side (types | drop zone) above ~820 px card width, stacked below; the strip re-flows,
  the footer stacks under 560 px. No stray "No video selected" text any more.

Logic is unchanged (same `_setVideo`, `VideoTools.captureVideoFrames`, `submitVideoItem`, same 50 MB / MP4-MOV checks).

## 3. Mobile preview -> realistic phone scenes (desktop)
Files: `desktop/lib/ui/widgets/phone_scenes.dart` (new), `phone_mockup.dart` (`hideStatusTime`), `asset_details.dart`.

Open any queue item -> **Mobile preview**. Next to the Aurora/Dark/Light/Blur background and Size slider there is now a
**scene chooser** (also as big buttons in the right "Realistic scenes" card):

| Scene | What you see |
|---|---|
| **Plain** | Just the file (as before). |
| **Lock screen** | Real lock screen over the wallpaper/video: live Dhaka clock + date (iOS style or Android style depending on the chosen frame), glass notification stack ("Zedge - Your upload is live", "Messages - Rafi"), flashlight/camera (iOS) or fingerprint + "Swipe up to unlock" (Android), status-bar clock hidden like a real phone. |
| **Home screen** | App icon grid (Phone, Messages, Camera, Zedge, Photos, YouTube, Instagram, WhatsApp, Spotify, Maps, Clock, Calendar, Settings, Facebook, TikTok) with rounded (iOS) or circular (Android) icons, page dots, glass dock, iOS clock + Zedge widgets or Android at-a-glance row + Google search pill. Wallpaper stays visible underneath. |
| **Zedge app** | The item page inside a dark Zedge-style app: app bar, media card (the wallpaper / video / ringtone player), type badge, title, "by <account>", downloads/likes, #tags from the item, a gradient CTA (Set as Wallpaper / Set Live Wallpaper / Set Charging Animation / Set as Ringtone) and bottom navigation. |
| **Incoming call** | The wallpaper blurred + dimmed like a real call screen. Caller "Ammu", pulsing avatar rings, shaking Accept button, "RINGTONE PLAYING - <your file>" card with animated equalizer bars. **Ringtone items auto-play** when the scene opens; **Accept** starts a call timer (mute / keypad / speaker / End), **Decline** ends the call - both stop the audio. iOS layout (name on top, Remind Me / Message) vs Android layout (avatar on top, Reply). |
| **Message** | Lock screen + a "Messages - Rafi" banner that slides in below the clock (spring animation), then a second "Zedge" notification. For ringtone items the audio plays as the notification sound. |

Extras: **Replay** (ring / slide the banner again), **Tour** (auto-cycles lock -> home -> app -> call -> message -> plain every 5 s -
great for showing a client, also in Fullscreen), every scene scales with the Size slider (all sizes are relative to the
screen width) and adapts to every device frame including the tablet (denser 6-column grid, compact call layout).
Leaving the preview stops any ringing audio and resets the scene.
