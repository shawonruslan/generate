# Keyboard shortcuts - MH Virtualcam

## In-app

| Key | Action |
|---|---|
| Space | Play / Pause |
| Right arrow / N | Next clip or image |
| Left arrow / B | Previous clip or image |
| + / - | Zoom in / out |
| Mouse wheel over preview | Zoom |
| Drag preview | Pan (while zoomed) |
| 0 | Reset zoom and pan |
| W / D | Pan up / right (while zoomed) |
| 1 - 9 | Jump to playlist item 1-9 |
| S | Start / Stop virtual camera |
| A | Toggle auto change |
| L | Cycle loop mode (Playlist / Single / Off) |
| F | Cycle fit mode (Fill / Fit / Stretch) |
| R | Cycle aspect ratio |
| Ctrl+O | Add files |
| Ctrl+Up / Ctrl+Down | Move selected playlist item |
| Delete | Remove selected playlist item |

## Global (work while Zoom / Teams / Discord is focused)

| Key | Action |
|---|---|
| Ctrl+Alt+S | Start / Stop virtual camera |
| Ctrl+Alt+N | Next clip or image |
| Ctrl+Alt+B | Previous clip or image |
| Ctrl+Alt+Space | Play / Pause |
| Ctrl+Alt+Up | Zoom in |
| Ctrl+Alt+Down | Zoom out |
| Ctrl+Alt+0 | Reset zoom |
| Ctrl+Alt+L | Cycle loop mode |
